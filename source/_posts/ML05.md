# 逻辑回归

* 该方法用于分类问题（二元分类，也就是y取0或1）

* 逻辑函数（sigmoid function）
  $$
  \sigma(x)=\frac{1}{1+e^{-x}}
  $$

## 决策边界

$$
\begin{aligned}
f_{\vec{w},b}(\vec{x}) &= \vec{w}\cdot\vec{x}+b\\[10pt]
z &= \vec{w}\cdot\vec{x}+b \\[10pt]
g(z) &= \frac{1}{1+e^{-z}}
\end{aligned}
$$

* 求 $z=0$ 时，**x 对应的函数**即为决策边界；

## 逻辑回归决定的成本函数

* 针对一个多参数，二分类问题，我们可以定义其函数为：$$f_{\vec{w},b}(\vec{x}) = \frac{1}{1 + e^{-(\vec{w} \cdot \vec{x} + b)}}$$
* 可以回顾一下线性回归的成本函数：$$J(\vec{w}, b) = \frac{1}{m} \sum_{i=1}^{m} \frac{1}{2} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right)^2$$
* 如果对二分类定义的函数使用线性回归的成本函数，那么构成的损失函数的图像是非凸成本函数，会包含许多局部最小值，导致梯度下降效率不高。这时候，需要重新定义，逻辑回归函数的成本函数。
* 这里特别定义：$$\frac{1}{2} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right)^2 = L\left( f_{\vec{w},b}(\vec{x}^{(i)}), y^{(i)} \right)$$
* 逻辑回归损失函数：$$L\left( f_{\vec{w},b}(\vec{x}^{(i)}), y^{(i)} \right) = \begin{cases} -\log\left( f_{\vec{w},b}(\vec{x}^{(i)}) \right) & \text{if } y^{(i)} = 1 \\ -\log\left( 1 - f_{\vec{w},b}(\vec{x}^{(i)}) \right) & \text{if } y^{(i)} = 0 \end{cases}$$

## 逻辑回归的简化版代价函数

* 可以将上述函数合并成一个式子：$$L\left( f_{\vec{w},b}(\vec{x}^{(i)}), y^{(i)} \right) = -y^{(i)} \log\left( f_{\vec{w},b}(\vec{x}^{(i)}) \right) - \left(1 - y^{(i)}\right) \log\left( 1 - f_{\vec{w},b}(\vec{x}^{(i)}) \right)$$
* 代价函数：$$J(\vec{w}, b) = \frac{1}{m} \sum_{i=1}^{m} \left[ L\left( f_{\vec{w},b}(\vec{x}^{(i)}), y^{(i)} \right) \right] = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log\left( f_{\vec{w},b}(\vec{x}^{(i)}) \right) + \left(1 - y^{(i)}\right) \log\left( 1 - f_{\vec{w},b}(\vec{x}^{(i)}) \right) \right]$$

## 将梯度下降用于逻辑回归

* 梯度下降：

  $$w_j = w_j - \alpha \frac{\partial}{\partial w_j} J(\vec{w}, b)$$

  $$b = b - \alpha \frac{\partial}{\partial b} J(\vec{w}, b)$$

* 将逻辑回归代价函数代入得到：

  $$w_j = w_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right) x_j^{(i)} \right]$$（这里的x_j表示，第i个参数的第j个特征）

  $$b = b - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right) \right]$$

# 过拟合

* 欠拟合：high bias
* 过拟合：对于训练集的适应效果太好，导致泛化能力很差，或者说对于其他特征很敏感。high variance

## 如何解决过拟合

* 获取更多的数据集
* 使用较少的（最相关的）特征（参数），但是可能会较大程度的影响模型效果
* 使用正则化减少参数的权重大小

## 正则化

* 正则化代价函数（线性）：$$\min_{\vec{w}, b} J(\vec{w}, b), \qquad J(\vec{w}, b)=\frac{1}{2m} \sum_{i=1}^{m} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right)^2 + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2$$

### 正则化线性回归实现梯度下降

* 梯度下降：

  $$\text{repeat } \{$$

  $$w_j = w_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} \left[ \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right) x_j^{(i)} \right] + \frac{\lambda}{m} w_j \right]$$

  $$b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right)$$

  $$\} \text{ simultaneous update}$$

### 正则化逻辑回归实现梯度下降

* $$\min_{\vec{w}, b} J(\vec{w}, b), \qquad J(\vec{w}, b)=-\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log\left( f_{\vec{w},b}(\vec{x}^{(i)}) \right) + \left(1 - y^{(i)}\right) \log\left( 1 - f_{\vec{w},b}(\vec{x}^{(i)}) \right) \right] + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2$$

* $$\text{repeat } \{ \quad w_j = w_j - \alpha \frac{\partial}{\partial w_j} J(\vec{w}, b) \quad (j = 1 \ldots n), \quad b = b - \alpha \frac{\partial}{\partial b} J(\vec{w}, b) \quad \}$$

* $$w_j = w_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right) x_j^{(i)} + \frac{\lambda}{m} w_j \right]$$

  $$b = b - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} \left( f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)} \right) \right]$$

## 1. 程序中的参数分别对应什么

| 数学符号 / 设置 | 代码中的变量 | 主要影响 |
| --- | --- | --- |
| $\vec{w}$ | `weights[1...]` | 每个特征对分类结果的影响强度 |
| $b$ | `weights[0]` | 整体平移决策边界，不参与 L2 正则化 |
| $\alpha$ | `learningRate` | 每次梯度更新走多远；过大可能震荡或发散 |
| $\lambda$ | `lambdaOptions[lambdaIndex]` | 收缩权重，控制模型对复杂特征的依赖程度 |
| epoch | `samplesSeen / train.length` | 全部训练样本被使用过多少遍 |
| 特征次数 | `linear / quadratic / degree6` | 决定模型最多能表示多复杂的边界 |

需要特别区分：**特征次数决定模型有没有能力弯曲，$\lambda$ 决定是否压制这种能力。** $\lambda$ 并不是直接修改边界线，而是先改变权重，再间接改变预测概率和边界。

## 2. 构建带随机性的数据

实验先从截断高斯分布采样 $x_1,x_2$，然后通过真实边界计算概率，最后按伯努利分布抽取标签。这比用一条曲线把标签硬切成 0 和 1 更符合现实：即使两个样本位置相近，它们也不一定拥有相同标签。

```javascript
function trueBoundary(x1) {
  return 0.42 * x1 * x1 - 0.08 * x1 - 0.65;
}

function generatePoint(rng, noise, labelFlipRate) {
  const x1 = Math.max(-2.65, Math.min(2.65, normal(rng) * 1.16));
  const x2 = Math.max(-2.35, Math.min(2.35, normal(rng) * 1.02));

  // noise 越大，Sigmoid 越平缓，边界附近的类别重叠越明显。
  const logit = (x2 - trueBoundary(x1)) / noise;
  let y = rng() < sigmoid(logit) ? 1 : 0;

  // 模拟现实中的标注错误或测量错误。
  if (rng() < labelFlipRate) y = 1 - y;
  return { x1, x2, y };
}
```

页面使用固定种子的伪随机数生成器，因此相同种子会得到完全相同的数据。比较不同 $\lambda$ 时应保持种子不变，否则差异可能来自数据变化，而不是正则化。

数据按类别进行 75%/25% 分层划分：

- 训练集参与梯度更新；
- 测试集只用于观察泛化能力；
- 均值、标准差只由训练集计算，避免测试集信息泄漏。

## 3. 构造特征并只用训练集标准化

线性模型只有 $x_1,x_2$，二次模型加入 $x_1^2,x_1x_2,x_2^2$。六次模型包含所有总次数不超过 6 的二元单项式，共 27 个特征，加上偏置后一共 28 个参数。

```javascript
function rawFeatures(point, model) {
  const a = (point.x1 - stats.mean1) / stats.sd1;
  const b = (point.x2 - stats.mean2) / stats.sd2;
  const degree = model === "linear" ? 1 : model === "quadratic" ? 2 : 6;
  const values = [];

  for (let total = 1; total <= degree; total++) {
    for (let p1 = total; p1 >= 0; p1--) {
      const p2 = total - p1;
      values.push((a ** p1) * (b ** p2));
    }
  }
  return values;
}
```

高次幂会迅速放大数值，因此多项式展开后还要逐列标准化。统计量仍然只能来自训练集：

```javascript
function fitFeatureStats(train) {
  const rows = train.map(point => rawFeatures(point, model));
  const count = rows[0].length;
  const means = Array.from(
    { length: count },
    (_, j) => rows.reduce((sum, row) => sum + row[j], 0) / rows.length
  );
  const sds = means.map((mean, j) =>
    Math.sqrt(
      rows.reduce((sum, row) => sum + (row[j] - mean) ** 2, 0) / rows.length
    ) || 1
  );
  return { means, sds };
}

function features(point) {
  const raw = rawFeatures(point, model);
  const scaled = raw.map(
    (value, j) => (value - featureStats.means[j]) / featureStats.sds[j]
  );
  return [1, ...scaled]; // 索引 0 固定为 1，对应偏置 b。
}
```

标准化很重要，因为 L2 惩罚的是权重数值。如果不同特征量纲相差很大，单纯比较权重大小或使用同一个 $\lambda$ 就不公平。

## 4. 稳定地计算 Sigmoid

直接计算 `Math.exp(-z)` 时，极端的 $z$ 可能造成数值溢出。可以根据正负分支计算：

```javascript
function sigmoid(z) {
  if (z >= 0) {
    return 1 / (1 + Math.exp(-Math.min(z, 40)));
  }
  const expZ = Math.exp(Math.max(z, -40));
  return expZ / (1 + expZ);
}

function dot(a, b) {
  return a.reduce((sum, value, i) => sum + value * b[i], 0);
}

function predictProbability(point) {
  return sigmoid(dot(weights, features(point)));
}
```

## 5. 交叉熵和 L2 正则项

程序真正优化的目标为：

$$
J(\vec{w},b)
=\underbrace{-\frac{1}{m}\sum_{i=1}^{m}
\left[y^{(i)}\log \hat y^{(i)}+(1-y^{(i)})\log(1-\hat y^{(i)})\right]}_{\text{交叉熵}}
+\underbrace{\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^2}_{\text{L2 正则项}}
$$

代码中把概率限制在安全范围，避免出现 `log(0)`：

```javascript
function evaluate(dataset, includeRegularization) {
  let loss = 0;
  let correct = 0;

  for (const point of dataset) {
    const p = sigmoid(dot(weights, features(point)));
    const safeP = Math.min(1 - 1e-12, Math.max(1e-12, p));
    loss += -(point.y * Math.log(safeP)
      + (1 - point.y) * Math.log(1 - safeP));
    correct += (p >= 0.5 ? 1 : 0) === point.y ? 1 : 0;
  }

  loss /= dataset.length;

  if (includeRegularization) {
    // slice(1) 排除了索引 0 的偏置 b。
    const squaredNorm = weights.slice(1)
      .reduce((sum, w) => sum + w * w, 0);
    loss += lambda * squaredNorm / (2 * train.length);
  }

  return { loss, accuracy: correct / dataset.length };
}
```

页面显示的训练损失和测试损失都**不包含** L2 项，方便公平比较；梯度下降和早停判断使用的训练目标则包含 L2 项。

## 6. 正则化逻辑回归最核心的梯度更新

对单个权重 $w_j$，数据项的梯度为：

$$
\frac{1}{m}\sum_{i=1}^{m}(\hat y^{(i)}-y^{(i)})x_j^{(i)}
$$

L2 项的导数为：

$$
\frac{\partial}{\partial w_j}
\left(\frac{\lambda}{2m}w_j^2\right)
=\frac{\lambda}{m}w_j
$$

合并后对应下面的代码：

```javascript
function oneUpdate(batch) {
  const gradient = new Array(weights.length).fill(0);

  // 1. 计算当前批次的交叉熵梯度。
  for (const point of batch) {
    const x = features(point);
    const probability = sigmoid(dot(weights, x));
    const error = probability - point.y;

    for (let j = 0; j < gradient.length; j++) {
      gradient[j] += error * x[j] / batch.length;
    }
  }

  // 2. 加入 L2 梯度。j 从 1 开始，因此偏置 weights[0] 不被惩罚。
  for (let j = 1; j < gradient.length; j++) {
    gradient[j] += (lambda / train.length) * weights[j];
  }

  // 3. 所有参数使用同一轮旧梯度同时更新。
  for (let j = 0; j < weights.length; j++) {
    weights[j] -= learningRate * gradient[j];
  }
}
```

这是整个正则化逻辑回归实现中最重要的一段。可以把每一项理解为：

```text
新权重 = 旧权重 - 学习率 ×（分类误差产生的梯度 + 正则化产生的梯度）
```

其中正则梯度 $(\lambda/m)w_j$ 总是把非零权重往 0 的方向拉。$\lambda$ 越大，拉回去的力量越强。

### 为什么偏置不正则化？

偏置 $b$ 只负责整体移动边界，不表示模型对某个输入特征的依赖程度。通常只惩罚 $w_1,\ldots,w_n$，因此代码中的正则循环从 `j = 1` 开始。

### 批量、小批量和随机梯度的区别

三种方法使用同一个 `oneUpdate()`，区别只是传入的 `batch` 大小：

```javascript
if (optimizer === "batch") batchSize = train.length;
if (optimizer === "mini")  batchSize = Math.min(16, train.length);
if (optimizer === "sgd")   batchSize = 1;
```

- 批量梯度：每次使用全部训练样本，轨迹稳定；
- 小批量梯度：计算效率与稳定性之间的折中；
- 随机梯度：每次只看一个样本，轨迹抖动更明显。

## 7. 训练轮数和早停

epoch 不能直接等同于更新次数。一次批量更新等于 1 epoch，但随机梯度需要看到全部 $m$ 个样本才等于 1 epoch：

```javascript
function currentEpoch() {
  return samplesSeen / train.length;
}
```

普通实验会开启早停：至少训练 10 epoch，若连续 10 epoch 没有超过 `1e-4` 的目标函数改善，就停止训练。专门观察过拟合时应关闭早停，否则模型可能在测试损失明显回升之前就停下。

## 8. 不能只看边界判断过拟合

实验中同时显示四类证据：

1. **最强信号：** 训练损失继续下降，但测试损失开始上升；
2. **泛化差距：** 训练准确率明显高于测试准确率；
3. **比较指标：** 在相同数据和特征尺度下，权重范数 $\lVert w\rVert$ 变得很大；
4. **辅助证据：** 边界出现不必要的弯曲。

边界弯曲本身不等于过拟合，因为真实规律也可能是弯曲的。准确率也可能不敏感：预测从 0.55 变成错误且自信的 0.99 时，准确率都只记作一次错误，但交叉熵会显著增大。因此应优先观察训练/测试损失是否分叉。

| 实验 | 样本 | 特征 | $\lambda$ | 标签翻转 | 早停 | 重点观察 |

| 欠拟合 | 160 | 线性 | 0.1 | 0% | 开 | 直线无法还原真实曲线 |
