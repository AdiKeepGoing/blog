DATA PROTOCOL

数据怎样被构建？

实验数据可复现，但不会“整齐得不真实”。每个标签来自概率采样，因此边界附近自然存在重叠。

GENERATIVE PROCESS

先生成特征，再按概率决定标签

p(y=1|x) = σ(x₂ − 0.42x₁² + 0.08x₁ + 0.65)/τ

x₁、x₂ 来自截断高斯分布；τ 由“数据噪声”控制。τ 越高，边界附近两类样本越容易交叠。

03

BEGINNER'S MAP

不要只看边界：这样判断过拟合

单个指标没有通用阈值。最可靠的是在同一数据、同一特征空间下做对照，并寻找多个信号同时出现。

强信号

训练损失 ↓，测试损失 ↑

模型继续迎合训练样本，但对没见过的数据变差。这是最典型的过拟合轨迹。

强信号

训练准确率高，测试准确率低

两者差距称为“泛化差距”。差距持续扩大，比单看某个准确率更有意义。

比较指标

权重范数 ‖w‖ 很大

说明模型依赖更极端的参数。请只在相同数据和特征尺度下比较；λ 增大通常会把它压小。

辅助证据

边界出现不必要的弯曲

弯曲本身不等于过拟合；真实规律也可能是弯的。必须结合测试损失和泛化差距判断。

CAUSE → EFFECT

参数改变后，先影响什么？

λ 正则强度λ ↑→权重 ‖w‖ ↓→边界通常更平滑适量可减轻过拟合；过大会欠拟合。
特征次数次数 ↑→参数数量 ↑→可拟合更复杂边界表达力更强，也更容易追随噪声。
样本量样本 ↑→估计更稳定→泛化通常更好小数据配复杂模型更容易过拟合。
噪声 / 标签翻转噪声 ↑→矛盾样本 ↑→测试更困难标签翻转模拟测量或标注错误。
训练轮数轮数 ↑→训练损失继续降→测试损失可能回升轮数本身不是越多越好。
学习率 αα ↑→每步更大→更快或震荡它主要影响优化过程，不直接控制模型复杂度。
